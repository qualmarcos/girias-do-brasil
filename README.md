# Gírias do Brasil

Aula interativa em slides sobre as gírias do português brasileiro para hispanofalantes: vocabulário por temas, mapa interativo por estados, figuras animadas e 11 atividades (ligue os pares, memória, verdadeiro ou falso, complete a frase, quiz…).

Abra `index.html` no navegador. Navegue com as setas do teclado, deslizando o dedo ou pela barra inferior.
